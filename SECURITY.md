# Security Policy

This is experimental research software, not a safety-certified engineering
tool. Do not use its predictions as the sole basis for medical, structural,
transportation, pressure-bearing, protective, or other safety-critical parts.

Please report code-execution, dependency, archive-extraction, or path-handling
vulnerabilities privately through GitHub's security-advisory feature. For
ordinary numerical defects, incorrect assumptions, or reproducibility
problems, open a public issue so the evidence can be discussed.

Only the latest commit on the default branch is supported. There is currently
no guaranteed response time.
